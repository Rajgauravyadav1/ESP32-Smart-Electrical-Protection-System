# Smart Electrical Protection & Monitoring System using ESP32

A smart electrical safety and monitoring system using ESP32, PZEM-004T, SH1106 OLED Display, and Relay Module.

## Features
- Real-time Voltage Monitoring
- Current Monitoring
- Power Measurement
- Energy Monitoring
- WiFi Web Dashboard
- Relay ON/OFF Control
- OLED Status Display
- Smart Electrical Protection

## Wiring

OLED → ESP32
SDA → D21
SCL → D22
VCC → 3.3V
GND → GND

PZEM → ESP32
TX → D16
RX → D17
VCC → 5V
GND → GND

Relay → ESP32
IN → D26
VCC → 5V
GND → GND
